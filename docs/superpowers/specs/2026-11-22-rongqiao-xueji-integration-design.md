# 融侨学迹真实引擎接入设计

日期：2026-11-22

## 意图

把已确认的“融侨学迹 · 紫藤档案”工作台接入现有知序真实计算引擎，保留本机优先、真实 Excel 导入和可追溯统计口径。用户在一次导入和长期档案两种工作方式之间切换时，使用同一套解析、计算和保存逻辑。

## 用户与任务

- 教务和年级组导入一场原始成绩，完成字段识别、数据核验、口径确认和分析表生成。
- 班主任和科任教师查看当前考试、班级与学科结果，继续进入学生明细或打印报表。
- 年级组选择同一届的多场考试，按稳定学生编码查看学生成长轨迹、班级趋势、学科趋势和综合名次。
- 使用 Mac 本机软件长期保存考试、教研记录和备份，并能从启动器进入快速出表或全校统筹。

## 目标

1. 将融侨学迹紫藤档案视觉与主要入口接入正式 `web/` 页面。
2. 快速导入支持真实文件选择、拖放、文件名状态、字段识别预览、核验提示、错误保留和保存为考试档案。
3. 多次分析支持按届别选择考试、实时显示选中数量、生成可见结果，并重点展示学生成长轨迹。
4. 历史计算使用稳定学生编码，保留考试名称、日期、班级、总分、各科分数、名次、弱科和参与次数。
5. 交付可直接启动的本机软件入口，并提供 macOS 应用包包装器和现有 Windows 启动器。

## 非目标

- 本轮不接入校园服务器、多人账号、权限分级或云端 S3。
- 本轮不改变已有排名、等级、有效分和薄弱学科的计算口径。
- 本轮不猜测未提供的体育成绩、教师归属、人工目标或跨届学生关系。
- 本轮不把静态样例数字当作真实分析结果，所有正式结果继续来自 `engine.py`。

## 约束

- 继续使用 Python 本地服务、SQLite、openpyxl 和 msoffcrypto-tool。
- 现有 25 项计算与服务测试必须继续通过。
- 上传文件最多 20MB，原始工作簿只读解析，密码只用于当次读取，不写入数据库或日志。
- 学生历史匹配优先使用稳定编码。匿名行继续保留本次结果，但不进入个人历次轨迹。
- 当前 UI 方向使用暖白紫底、墨紫文字、藤紫强调、宋体标题、等宽数字和低圆角档案层级。

## 方案

### 数据与计算

保留现有 `Dataset → analyze → Analysis` 链路。`exams` 表继续保存完整 Dataset 和当次 rules 快照。历史接口在现有综合名次基础上增加每场考试的学生明细字段，并支持 `exam_ids` 选择，避免 UI 在浏览器中重新猜测历史口径。

### 快速导入

融侨学迹主工作台的“快速分析本次考试”打开导入抽屉。抽屉先显示文件选择与拖放区，选择文件后调用 `/api/import`，展示识别到的字段、记录数、班级数、科目数和核验提示。错误状态保留当前文件和提示，用户可以重新选择。确认规则后调用 `/api/analyze`，保存动作继续调用 `/api/exams` 并重新读取校验。

### 多次分析

“多次分析”打开考试选择抽屉或结果页。选项显示考试名称、日期、届别和参与人数。至少选择两场后生成历史结果。结果页第一层显示学生搜索、参与次数、综合名次和历次名次，选中学生后显示总分、各科分数、得分率、弱科和班级变化轨迹。

### 页面与品牌

正式入口继续由 `web/index.html`、`web/quick.html` 和 `web/leader.html` 提供。可视品牌、标题、页脚、帮助页和启动器文案统一为“融侨学迹”。内部 Python 模块名和兼容旧数据的数据库格式继续保持不变。

### 打包

保留现有 `.command` 和 `.bat` 启动方式。新增 macOS `融侨学迹.app` 应用包包装器，启动本地服务并打开默认页面。应用包沿用现有运行时探测规则，首次安装仍通过安装脚本准备依赖。打包验证覆盖启动地址、快速入口、统筹入口和退出提示。

## 验收标准

- 使用随附真实匿名样例完成导入，能看到字段识别、记录数、班级数、科目数和核验提示。
- 未选择文件时不能进入导入核验成功状态，选中文件后才显示文件名和下一步状态。
- 保存一场考试后刷新页面，考试仍在档案中，规则和分析结果可重新读取。
- 选择三场同一届考试后，取消一场会同步更新数量和生成按钮，生成结果展示学生轨迹入口。
- 历史学生以稳定编码关联，姓名或班级变化不会制造第二个学生，匿名记录不进入个人历史。
- 切换考试后当前考试身份、摘要、更新时间、教研关注和趋势数据一致。
- 现有 Python 单元测试与服务测试全部通过，新增接口测试覆盖上述边界。
- 浏览器桌面和 390px 窄屏入口无控制台错误、横向溢出、失败图片或无法关闭的抽屉。
- macOS 启动器和应用包能启动本地服务，Windows 启动器文件保持可用。
