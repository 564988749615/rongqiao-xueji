使用说明与计算口径

小软件：一次导入，一次出表

  1. 选择 Excel 或 CSV，填写考试名称、年级和日期。原始表需要“班级”和学科列；姓名、学号可选。
  2. 查看导入核验。设置参加统计的班级、计入总分的科目；“01—20班”是可选范围，软件默认纳入表内全部班级。
  3. 生成后切换成绩排名、ABC、六层等级、有效分、班级统计、前N人数、薄弱科和数据核验。
  4. 复制当前表可直接粘贴到 Excel；下载 CSV 或完整多页 Excel，也可以打开打印报告后打印或存为 PDF。
  5. 需要长期保留时，主动点击“保存到全校平台”。未保存的成绩只在当前页面中，刷新后需要重新导入。

大软件：保存考试，持续查看

  1. 进入数据管理，导入并确认保存一场考试。也可从小软件转存。
  2. 全校总览按每个年级最新考试汇总人数与班数，各年级分别计算成绩。只显示已经导入的年级。
  3. 选择考试，按班级、学科查看均分、有效分与达标名单。点击学生查看各科排名及相对薄弱科。
  4. 同年级导入多次考试后可看趋势。个人历史需要稳定学号，或同班同名记录；匿名行不能跨考试识别。
  5. 历次趋势按相同的年级名称归组。若需要跨学年跟踪同一届，请统一使用“初2027届”等固定届别名称；不同届不要都归入同一个“初三”标签。
  6. 教研记录保存在本机，可重新打开查看。数据管理可导出备份、恢复备份、归档并恢复考试。
  7. 汇报模式收起导航并放大内容，按 Esc 退出。报表中心提供实际下载、复制与打印。

本版计算规则

  • 总分：只加勾选科目。缺分默认不纳入总分排名，可显式改成按0合计；原始空值仍保留。
  • 零分：默认不计入实考人数与均分，全零记录不参与排名；可选择保留真实0分。参与总分排名的学生，其有数值的单科成绩（含0）参与单科排名。
  • 排名：同分同名次，依次为1、2、2、4。年级与班级分别计算。
  • 有效分：真实有效人数乘比例后向下取整；不足1人时按第1名。按该位置确定分数线，同分全纳入。
  • 等级：ABC累计30%、80%、100%；六等级累计18%、30%、55%、80%、90%、100%。边界并列可能使实际比例变化。
  • 集中人数：同时达到总分和单科分界的人数。不把“集中数”误作一个没有定义分母的比例。
  • 薄弱科：按“总分名次−单科名次”从小到大选择，体育不参与；同值按固定学科顺序输出，不重复学科。表达的是相对位次，不是知识点诊断。
  • 历史综合：普通平均、去一次最好最差后的平均、加权平均，再融合并排序。缺考不当作0名。默认权重按考试先后递增，可在界面修改。
  • 满分：由用户确认填写。未填写时不计算得分率，不用最高得分猜满分。不同试卷趋势提供复盘线索，不直接表示教学增值。

本版修正了旧表的“表头算进人数”“新增班级漏合计”“并列重复弱科”。不能用一张当前原始表生成尚未提供的体育、历次成绩、教师任课历史或人工班级目标。

数据保存与运行

这是本机运行版。启动后保持启动窗口打开，浏览器访问 http://127.0.0.1:8877/。数据保存在软件目录的 data/zhixu.sqlite3。移动软件时请完整保留目录，或先下载 JSON 备份。

备份恢复按考试ID补入，不覆盖已存在的考试；归档可恢复。当前版本面向这台电脑使用，尚未配置校园服务器、多用户登录与校级权限。

打印页使用 A4 横向格式，表头重复。最终纸张、缩放、单双面与打印机在系统打印窗口选择。
